# STRprofilerR: Compare Short Tandem Repeat Profiles for Model Authentication

Compares short tandem repeat (STR) profiles to authenticate biomedical
models such as cell lines and xenografts against the primary tissue
samples they were derived from. Provides the Tanabe (Sorenson-Dice),
Masters (versus query), and Masters (versus reference) similarity
scores, heuristics for detecting sample mixing, flexible ingest of wide
and long profile formats, comparison against user-supplied reference
databases, and querying of the Cellosaurus knowledge base through the
CLASTR REST API. A command line application is included for use in
automated workflows.
